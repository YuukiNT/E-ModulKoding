Membuat Program yang Lebih Canggih

Materi ditulis dalam bahasa Python — sama seperti yang kamu praktikkan di Thonny/VS Code di lab komputer. Klik tiap pertemuan untuk membuka.

PERTEMUAN 1Struktur Logika Kompleks▾

A. Tujuan Pembelajaran

Menganalisis dan menerapkan struktur logika kompleks (nested if, nested loop, list methods, comparison chaining, fungsi modular) untuk merancang algoritma program secara sistematis.

B. Apersepsi

Bayangkan fungsi seperti "mesin pemroses": ada input yang masuk, ada proses di dalam mesin, lalu keluar output-nya. Fungsi dalam Python bekerja persis seperti itu.

C. Materi — Nested If & Comparison Chaining

Nested if adalah percabangan di dalam percabangan lain — dipakai saat ada lebih dari satu syarat yang harus dicek berurutan. Python juga punya jalan pintas comparison chaining untuk mengecek rentang nilai sekaligus.

nilai = 85
if 80 <= nilai <= 90:
    print("Nilai kamu di rentang 80-90!")

D. Materi — Nested Loop & Metode List

Nested loop adalah perulangan di dalam perulangan lain. Tipe data list punya metode bawaan yang sering dipakai: .append() (menambah data), .sort() (mengurutkan), .remove() dan .pop() (menghapus data).

antrean = []
antrean.append("Andi")
antrean.append("Sari")
pelanggan_pertama = antrean.pop(0)  # FIFO: yang pertama masuk, pertama dilayani
print(pelanggan_pertama)

E. Contoh Kode — Fungsi Konversi Suhu

Fungsi (def) membungkus kode agar bisa dipanggil ulang tanpa menulis ulang. return mengirim balik hasilnya.

def celsius_ke_fahrenheit(c):
    f = (c * 9/5) + 32
    return f

hasil = celsius_ke_fahrenheit(30)
print("Hasil dalam Fahrenheit:", hasil)

F. Coba Sendiri

Di Thonny/VS Code, ubah nilai c pada pemanggilan fungsi, lalu jalankan lagi programnya.

G. Tantangan 1

Buat fungsi fahrenheit_ke_kelvin(f) yang mengonversi Fahrenheit ke Kelvin, lalu uji dengan beberapa nilai berbeda.

H. Ringkasan

Struktur logika kompleks (nested if, nested loop, fungsi, metode list) memungkinkan program menyelesaikan masalah yang lebih dari satu langkah keputusan.

PERTEMUAN 2Kasir Cerdas & Strategi Algoritma▾

A. Tujuan Pembelajaran

Merancang dan memproduksi kode program terstruktur menggunakan variabel, kondisi bersarang, perulangan, serta strategi algoritma pada program Python (Kasir Cerdas).

B. Apersepsi

Pernah lihat kasir toko memberi poin belanja atau diskon otomatis? Di balik layar, itu program dengan percabangan bertingkat yang mengecek total belanjamu.

C. Materi — Program Kasir Cerdas (Diskon & Poin Berjenjang)

Ini kode asli yang kamu kembangkan bersama kelompok saat proyek Kasir Cerdas — menghitung poin belanja berdasarkan total transaksi:

total = int(input("Total belanja: "))
poin = 0

if total > 500000:
    poin += 5
elif total > 300000:
    poin += 3
elif total > 100000:
    poin += 2

print("Poin didapat:", poin)

D. Materi — Simulasi Antrean FIFO

Prinsip FIFO (First In First Out) — pelanggan yang datang duluan, dilayani duluan — dipakai untuk simulasi antrean, memakai .append() untuk menambah dan .pop(0) untuk melayani dari depan.

E. Materi — Strategi Algoritma Greedy

Algoritma Greedy selalu memilih langkah terbaik/terbesar di setiap tahap tanpa melihat keseluruhan hasil akhir — contohnya menentukan pecahan kembalian uang dengan jumlah lembar paling sedikit.

kembalian = 37000
pecahan = [20000, 10000, 5000, 2000, 1000]
hasil = []
for p in pecahan:
    while kembalian >= p:
        hasil.append(p)
        kembalian -= p
print(hasil)

F. Coba Sendiri

Ubah nilai total pada kode Kasir Cerdas dan cek apakah poin yang keluar sudah sesuai aturan diskon berjenjang.

G. Tantangan 2 (Proyek Kelompok)

Gabungkan program Kasir Cerdas dengan simulasi Antrean FIFO: setiap pelanggan dalam antrean dihitung poinnya berdasarkan total belanja masing-masing.

H. Ringkasan

Program yang canggih menggabungkan variabel, kondisi bersarang, dan strategi algoritma (seperti Greedy) untuk menyelesaikan masalah nyata secara efisien.

PERTEMUAN 3Pengenalan Debugging▾

A. Tujuan Pembelajaran

Mengidentifikasi 3 jenis bug (Syntax Error, Runtime Error, Logic Error) serta menerapkan teknik debugging untuk melacak dan memperbaiki kesalahan kode program Python.

B. Apersepsi

Program yang lebih canggih juga berarti lebih banyak kemungkinan bug. Seorang programmer yang baik bukan yang tidak pernah membuat bug, tapi yang cepat menemukan dan memperbaikinya.

C. Materi — 3 Jenis Bug

  • Syntax Error — kesalahan penulisan aturan bahasa (misal lupa tanda titik dua :).
  • Runtime Error — program berhenti saat dijalankan karena hal tak terduga (misal membagi dengan nol).
  • Logic Error — program berjalan lancar tanpa pesan error, tapi hasilnya salah.

D. Materi — Membaca Traceback & try-except

Pesan error di Python disebut Traceback — berisi petunjuk baris mana yang bermasalah. Blok try-except dipakai untuk menangani error agar program tidak langsung berhenti.

try:
    angka = int(input("Masukkan angka: "))
    print(100 / angka)
except:
    print("⚠️ Terjadi kesalahan, pastikan input berupa angka bukan 0.")

F. Langkah Debugging

  1. Baca pesan Traceback untuk tahu baris mana yang bermasalah.
  2. Tambahkan print() di beberapa titik untuk melacak nilai variabel.
  3. Telusuri logika program baris demi baris.
  4. Perbaiki satu bug dalam satu waktu, lalu uji ulang.
