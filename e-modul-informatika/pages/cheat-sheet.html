📋 Cheat Sheet Python — Bab 2

Rangkuman semua syntax yang dipelajari di Bab 2. Simpan/print buat ditempel di meja belajar.

Cheat Sheet Python — Koding & AI Bab 2 · SMP Negeri 9 Samarinda

Nested If

if syarat1:
    if syarat2:
        # dijalankan kalau
        # syarat1 DAN syarat2
        # sama-sama benar
        ...

Comparison Chaining

if 80 <= nilai <= 90:
    print("di rentang!")

# sama dengan:
if nilai >= 80 and nilai <= 90:
    ...

Nested Loop

for i in range(3):
    for j in range(2):
        print(i, j)
# luar jalan 1x -> dalam
# jalan penuh dulu

Metode List

data = []
data.append(x)   # tambah di akhir
data.sort()       # urutkan
data.pop(0)       # ambil & hapus depan
data.pop()        # ambil & hapus akhir
data.remove(x)    # hapus berdasar isi

Fungsi (def & return)

def nama_fungsi(param):
    hasil = param * 2
    return hasil

x = nama_fungsi(5)  # x = 10

FIFO (Antrean)

antrean = []
antrean.append("A")
antrean.append("B")
depan = antrean.pop(0)
# depan = "A" (masuk duluan,
# keluar duluan)

Algoritma Greedy (Kembalian)

pecahan = [20000, 10000, 5000]
hasil = []
for p in pecahan:
    while kembalian >= p:
        hasil.append(p)
        kembalian -= p

try-except

try:
    x = int(input("Angka: "))
    print(100 / x)
except:
    print("Input tidak valid!")
