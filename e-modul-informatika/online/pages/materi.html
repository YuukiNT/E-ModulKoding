PERTEMUAN 1Struktur Logika Kompleks▾

A. Tujuan Pembelajaran

Menganalisis dan menerapkan struktur logika kompleks (nested if, nested loop, list methods, comparison chaining, fungsi modular) untuk merancang algoritma program secara sistematis.

B. Apersepsi

Pernah pakai blender buat bikin jus? Kamu masukkan buah (itu input), blender kerja menghaluskan (itu proses), dan keluar jus (itu output). Fungsi dalam Python bekerja persis seperti blender itu — dan sepanjang pertemuan ini, kamu akan belajar bikin "mesin-mesin" logika yang lebih canggih dari sekadar satu blender: ada yang punya banyak saklar pilihan (percabangan bertingkat), ada yang mengulang proses berkali-kali dengan pola berlapis (perulangan bertingkat).

C. Materi — Nested If (Percabangan Bersarang)

Sejauh ini kamu sudah kenal if biasa: satu syarat, satu keputusan. Tapi di dunia nyata, keputusan sering butuh lebih dari satu syarat. Contoh: sebuah wahana di taman bermain hanya boleh dinaiki kalau tinggi badan di atas 120 cm DAN punya tiket. Ada dua syarat yang harus dicek, dan syarat kedua baru dicek kalau syarat pertama sudah terpenuhi. Inilah yang disebut nested if — percabangan if yang diletakkan di dalam percabangan if lain.

tinggi = 130
punya_tiket = True

if tinggi >= 120:
    if punya_tiket:
        print("Boleh naik wahana!")
    else:
        print("Beli tiket dulu ya.")
else:
    print("Tinggi badan belum cukup.")

Perhatikan baik-baik: if punya_tiket ditulis lebih menjorok ke dalam (ada indentasi tambahan) dibanding if tinggi >= 120. Indentasi inilah yang memberi tahu Python bahwa syarat kedua itu "bersarang" di dalam syarat pertama — kalau syarat pertama salah, Python bahkan tidak akan pernah mengecek syarat kedua sama sekali.

D. Materi — Comparison Chaining (Jalan Pintas Mengecek Rentang)

Kadang kita perlu mengecek apakah sebuah nilai berada di antara dua batas, misalnya nilai ujian 80 sampai 90. Cara panjangnya memakai and, tapi Python punya jalan pintas yang lebih rapi bernama comparison chaining.

# Cara panjang
nilai = 85
if nilai >= 80 and nilai <= 90:
    print("Nilai kamu di rentang 80-90!")

# Jalan pintas comparison chaining -- hasilnya sama persis
if 80 <= nilai <= 90:
    print("Nilai kamu di rentang 80-90!")

Dua kode di atas melakukan hal yang persis sama — comparison chaining cuma bikin tulisannya lebih pendek dan lebih gampang dibaca, seperti membaca kalimat matematika biasa: "80 lebih-kecil-sama-dengan nilai lebih-kecil-sama-dengan 90".

E. Materi — Nested Loop (Perulangan Bersarang)

Bayangkan kalender satu bulan: ada beberapa minggu, dan setiap minggu punya 7 hari. Untuk "mengunjungi" setiap hari dalam sebulan, kamu sebenarnya melakukan dua perulangan sekaligus — luar (minggu) dan dalam (hari). Itulah nested loop: perulangan for yang diletakkan di dalam perulangan for lain.

for minggu in range(1, 3):
    for hari in range(1, 8):
        print("Minggu", minggu, "Hari ke-", hari)

Setiap kali perulangan luar (minggu) berjalan satu langkah, perulangan dalam (hari) akan berjalan penuh dari awal sampai akhir dulu. Jadi urutan cetaknya: Minggu 1 Hari 1, Minggu 1 Hari 2, ... sampai Minggu 1 Hari 7, baru lanjut ke Minggu 2 Hari 1, dan seterusnya.

F. Materi — Metode List (append, sort, remove, pop)

List di Python itu seperti rak buku yang isinya bisa kamu ubah kapan saja — tambah buku baru, urutkan berdasarkan judul, atau ambil satu buku dari rak. Ada empat "perintah rak buku" yang paling sering dipakai:

antrean = []
antrean.append("Andi")   # tambah data baru di paling belakang
antrean.append("Sari")
print(antrean)              # ['Andi', 'Sari']

antrean.sort()               # urutkan (alfabet untuk teks)
print(antrean)              # ['Andi', 'Sari'] -- sudah urut A dulu

pelanggan_pertama = antrean.pop(0)   # ambil & hapus data di posisi 0 (paling depan)
print(pelanggan_pertama)    # Andi
print(antrean)              # ['Sari'] -- Andi sudah keluar dari list

Metode .pop(0) di atas persis menggambarkan prinsip FIFO (First In First Out) — orang yang pertama masuk antrean adalah yang pertama dilayani (dan pertama keluar dari list). Ini akan kamu pakai lagi di Pertemuan 2 untuk simulasi antrean pelanggan.

G. Materi — Fungsi Modular (def & return)

Ingat analogi blender tadi? Fungsi adalah cara kita "membungkus" sekumpulan perintah jadi satu mesin yang bisa dipakai berkali-kali tanpa perlu menulis ulang kodenya. Kata kunci def dipakai untuk membuat fungsi baru, dan return dipakai untuk mengirim balik hasilnya keluar dari fungsi.

def celsius_ke_fahrenheit(c):
    f = (c * 9/5) + 32
    return f

hasil = celsius_ke_fahrenheit(30)
print("Hasil dalam Fahrenheit:", hasil)

Bagian (c) di dalam kurung disebut parameter — semacam "lubang input" pada mesin. Saat kita memanggil celsius_ke_fahrenheit(30), angka 30 itu disebut argumen yang dimasukkan ke lubang input c. Keuntungan besar memakai fungsi: kalau besok kamu butuh konversi suhu lagi di bagian lain program, kamu tinggal panggil celsius_ke_fahrenheit(...) lagi, tanpa perlu menulis ulang tiga baris rumusnya.

H. Coba Sendiri

Di Thonny/VS Code, ubah nilai c pada pemanggilan fungsi, lalu jalankan lagi programnya. Coba juga tebak dulu hasilnya sebelum program dijalankan — ini melatih kemampuan berpikir komputasionalmu.

I. Tantangan 1

Buat fungsi fahrenheit_ke_kelvin(f) yang mengonversi Fahrenheit ke Kelvin, lalu uji dengan beberapa nilai berbeda. Petunjuk rumus: Kelvin = (Fahrenheit − 32) × 5/9 + 273.15.

J. Ringkasan

Struktur logika kompleks (nested if, comparison chaining, nested loop, metode list, dan fungsi) memungkinkan program menyelesaikan masalah yang butuh lebih dari satu langkah keputusan — dan membuat kodemu lebih rapi karena tidak perlu ditulis berulang-ulang.

PERTEMUAN 2Kasir Cerdas & Strategi Algoritma▾

A. Tujuan Pembelajaran

Merancang dan memproduksi kode program terstruktur menggunakan variabel, kondisi bersarang, perulangan, serta strategi algoritma pada program Python (Kasir Cerdas).

B. Apersepsi

Pernah belanja di minimarket dan dapat poin otomatis, atau diskon makin besar kalau belanja makin banyak? Di balik layar kasir itu, ada program sederhana yang mengecek total belanjamu lewat serangkaian if dan elif bertingkat — persis seperti yang akan kamu bangun hari ini.

C. Materi — Program Kasir Cerdas (Diskon & Poin Berjenjang)

Ini kode asli yang kamu kembangkan bersama kelompok saat proyek Kasir Cerdas — menghitung poin belanja berdasarkan total transaksi. Perhatikan bagaimana elif dipakai berurutan dari syarat terbesar ke terkecil:

total = int(input("Total belanja: "))
poin = 0

if total > 500000:
    poin += 5
elif total > 300000:
    poin += 3
elif total > 100000:
    poin += 2

print("Poin didapat:", poin)

Kenapa urutannya harus dari syarat terbesar dulu? Karena Python mengecek elif dari atas ke bawah dan langsung berhenti begitu satu syarat terpenuhi. Kalau belanja 600.000, syarat pertama (>500.000) langsung benar dan Python berhenti di situ — tidak sempat mengecek syarat-syarat di bawahnya lagi. Coba bayangkan kalau urutannya dibalik (terkecil dulu) — poin 600.000 akan salah dihitung sebagai poin 2, bukan 5!

D. Materi — Simulasi Antrean FIFO

Ingat prinsip FIFO (First In First Out) dari Pertemuan 1? Pelanggan yang datang duluan, dilayani duluan — sama seperti antrean di kasir sungguhan. Kita bisa menggabungkan .append() untuk menambah pelanggan baru ke antrean, dan .pop(0) untuk melayani pelanggan paling depan.

antrean_kasir = []
antrean_kasir.append("Budi")
antrean_kasir.append("Citra")
antrean_kasir.append("Dedi")

while len(antrean_kasir) > 0:
    dilayani = antrean_kasir.pop(0)
    print("Melayani:", dilayani)

E. Materi — Strategi Algoritma Greedy

Bayangkan kamu jadi kasir yang harus memberi kembalian dengan lembar uang sesedikit mungkin. Cara paling logis: ambil dulu lembar bernilai paling besar yang masih muat, baru sisanya diselesaikan dengan lembar yang lebih kecil, diulang terus sampai kembaliannya pas. Cara berpikir "selalu ambil pilihan terbaik yang tersedia saat itu juga" inilah yang disebut algoritma Greedy (rakus) — greedy tidak memikirkan jauh ke depan, cuma fokus pada langkah terbaik di depan mata.

kembalian = 37000
pecahan = [20000, 10000, 5000, 2000, 1000]
hasil = []
for p in pecahan:
    while kembalian >= p:
        hasil.append(p)
        kembalian -= p
print(hasil)   # [20000, 10000, 5000, 2000]

Perhatikan: perulangan luar (for p in pecahan) berjalan dari pecahan terbesar ke terkecil, dan perulangan dalam (while) mengambil pecahan yang sama berkali-kali selama kembalian masih cukup besar. Ini contoh nested loop juga, sekaligus contoh strategi Greedy dipakai nyata.

F. Coba Sendiri

Ubah nilai total pada kode Kasir Cerdas dan cek apakah poin yang keluar sudah sesuai aturan diskon berjenjang. Coba juga angka pas di batas (misalnya persis 500000) — apakah dapat poin 5 atau poin 3? Ini melatih ketelitianmu membaca operator perbandingan.

G. Tantangan 2 (Proyek Kelompok)

Gabungkan program Kasir Cerdas dengan simulasi Antrean FIFO: setiap pelanggan dalam antrean dihitung poinnya berdasarkan total belanja masing-masing.

H. Ringkasan

Program yang canggih menggabungkan variabel, kondisi bersarang, dan strategi algoritma (seperti Greedy) untuk menyelesaikan masalah nyata secara efisien — dan urutan pengecekan syarat (dari besar ke kecil) ternyata sangat menentukan hasil akhirnya.

PERTEMUAN 3Pengenalan Debugging▾

A. Tujuan Pembelajaran

Mengidentifikasi 3 jenis bug (Syntax Error, Runtime Error, Logic Error) serta menerapkan teknik debugging untuk melacak dan memperbaiki kesalahan kode program Python.

B. Apersepsi

Program yang lebih canggih juga berarti lebih banyak kemungkinan bug (kesalahan). Kabar baiknya: semua programmer, sepintar apapun mereka, pasti pernah bikin bug — bahkan setiap hari. Bedanya, programmer yang baik bukan yang tidak pernah salah, tapi yang cepat dan sistematis dalam menemukan serta memperbaiki kesalahannya.

C. Materi — 3 Jenis Bug

Ada tiga jenis kesalahan program yang perlu kamu kenali, karena cara mendeteksinya berbeda-beda:

  • Syntax Error — kesalahan penulisan aturan bahasa, seperti typo dalam Bahasa Indonesia. Contoh: lupa tanda titik dua : setelah if, atau lupa tutup tanda kurung. Python langsung menolak menjalankan program sama sekali kalau ada Syntax Error, jadi ini yang paling mudah disadari.
  • Runtime Error — program sempat berjalan, tapi tiba-tiba berhenti di tengah jalan karena hal tak terduga, misalnya membagi dengan angka nol, atau mencoba mengambil data list di posisi yang tidak ada.
  • Logic Error — ini yang paling licik: program berjalan lancar dari awal sampai akhir, tidak ada pesan error sama sekali, tapi hasilnya salah. Contohnya rumus yang salah ditulis, atau syarat percabangan yang terbalik.

D. Materi — Membaca Traceback

Ketika Python menemukan Syntax Error atau Runtime Error, dia akan menampilkan pesan yang disebut Traceback. Jangan takut kalau pesannya panjang dan berwarna merah — di baris paling bawah biasanya ada info paling penting: nomor baris yang bermasalah dan jenis errornya. Kebiasaan baik: selalu baca dari baris paling bawah dulu.

E. Materi — Menangani Error dengan try-except

Kadang kita tidak bisa mencegah error sepenuhnya — misalnya kalau pengguna program salah memasukkan data. Blok try-except dipakai supaya program tidak langsung berhenti total, tapi memberi pesan yang ramah dan tetap lanjut berjalan.

try:
    angka = int(input("Masukkan angka: "))
    print(100 / angka)
except:
    print("⚠️ Terjadi kesalahan, pastikan input berupa angka bukan 0.")

Cara bacanya: Python akan "mencoba" (try) menjalankan kode di dalamnya. Kalau berhasil, blok except dilewati begitu saja. Tapi kalau di tengah jalan terjadi error apapun, Python langsung lompat ke blok except dan menjalankan kode di situ, alih-alih menghentikan seluruh program.

G. Langkah Debugging yang Sistematis

  1. Baca pesan Traceback untuk tahu baris mana yang bermasalah (kalau ada pesan errornya).
  2. Tambahkan print() di beberapa titik untuk melacak nilai variabel — ini seperti memasang "kamera CCTV" di beberapa titik program untuk melihat apa yang sebenarnya terjadi.
  3. Telusuri logika program baris demi baris, seolah-olah kamu adalah komputer yang menjalankannya satu per satu.
  4. Perbaiki satu bug dalam satu waktu, lalu jalankan ulang untuk memastikan perbaikanmu benar-benar berhasil sebelum lanjut mencari bug lain.

H. Tantangan 3

Ambil program Kasir Cerdas dari Pertemuan 2, lalu tambahkan blok try-except agar program tidak error jika pengguna memasukkan huruf, bukan angka.

I. Ringkasan

Debugging adalah keterampilan penting bagi setiap programmer: mengenali jenis bug (Syntax, Runtime, atau Logic Error), menelusuri Traceback, dan memperbaiki kesalahan secara sistematis satu per satu — bukan asal coba-coba.
